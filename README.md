# WILD-CER 🐾

## AI-Powered Wildlife Emergency Rescue Platform

WILD-CER is a project developed to help in reporting and managing wildlife emergency cases. The platform allows users to submit information about a wildlife incident and helps organize and process the details for further action.

## Features

- User registration and login
- Wildlife emergency reporting
- Image processing
- Text processing
- Incident scoring
- Data storage and management
- Basic data visualization

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Machine Learning
- Image Processing

- ## Project Files

- `app.py` - Main application
- `auth.py` - User authentication
- `database.py` - Database operations
- `image_processing.py` - Image processing
- `text_processing.py` - Text processing
- `scoring.py` - Incident scoring
- `visualization.py` - Data visualization
- `requirements.txt` - Required Python libraries

## How to Run

1. Clone the repository:

   git clone https://github.com/aaryawange/WILD-CER.git

2. Open the project folder:

   cd WILD-CER

3. Install the required libraries:

   pip install -r requirements.txt

4. Run the application:

   python app.py
